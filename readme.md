# Bino Service Demo

A simple web application to generate **WhatsApp query links** for service providers like Plumbers, Electricians, and Carpenters.  

The project consists of:  

- **Backend:** Spring Boot REST API deployed on Render with Docker  
- **Frontend:** React app for user interaction, deployed as a static site  

---

## Features

- Select service category (Plumber, Electrician, Carpenter)  
- Enter query and location  
- Generate a ready-to-send **WhatsApp link**  
- Modern responsive UI with card-style form  

---

## Technologies Used

- **Backend:** Java, Spring Boot, Maven, Docker  
- **Frontend:** React, Axios, CSS  
- **Deployment:** Render (Web Service)  
- **Docker Images:** `eclipse-temurin:17-jdk-focal` for backend
